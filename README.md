# Sales Analysis Dashboard using Power BI – Atliq Hardware

## Project Overview
This project focuses on analyzing sales performance for Atliq Hardware using Microsoft Power BI.
The company receives sales data from multiple regional managers in the form of Excel files, which makes analysis difficult due to the lack of consolidation and visualization.

To solve this problem, an interactive Power BI dashboard was developed to provide clear, data-driven insights.



##  Objectives (Aims Grid)
- Consolidate multiple Excel files into a single data model
- Analyze sales trends year-wise and month-wise
- Evaluate market-wise, customer-wise, and product-wise performance
- Identify sales decline, risks, and growth opportunities
- Enable quick and data-driven decision-making using an interactive dashboard


##  Problem Statement
The sales manager faced difficulty in analyzing performance due to static, unstructured, and scattered Excel reports.
As a result, identifying declining trends, comparing markets and customers, and taking data-driven decisions was challenging.



##  Tools Used
- Microsoft Power BI
- Power Query (ETL)
- DAX
- Microsoft Excel



##  ETL Process
**Extract**
- Data extracted from multiple Excel files received from regional managers

**Transform**
- Removed null and duplicate records
- Filtered invalid sales values
- Converted currency from USD to INR
- Standardized column names and formats

**Load**
- Cleaned data loaded into Power BI for modeling and visualization


##  Dashboard Features
- Total Revenue KPI
- Total Sales Quantity KPI
- Revenue & Sales Quantity by Market
- Year-wise & Month-wise Sales Trend
- Top 5 Customers Analysis
- Top 5 Products Analysis
- Interactive Year & Month slicers


## Key Insights
- Sales peaked in 2018 and declined significantly in 2020 due to COVID-19
- Delhi NCR consistently generates the highest revenue
- Some markets show high sales quantity but lower revenue
- Revenue dependency on a few customers increases business risk
- Certain products show performance volatility


## Conclusion
This dashboard replaces static Excel reports and enables proactive, insight-driven sales analysis.
It helps management understand performance trends, identify risks, and take corrective actions.
